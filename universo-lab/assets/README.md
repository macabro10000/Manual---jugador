2. `video-animal.webp` — miniatura horizontal de video, 1200×800.
3. `news-space.webp` — imagen editorial de ciencia/espacio, 1200×800.

6. `curiosity-clouds.webp` — curiosidad visual, 1200×800.
7. `news-world.webp` — noticia/mundo, 1200×800.
8. `video-ideas.webp` — ideas/creatividad, 1200×800.
9. `curiosity-questions.webp` — curiosidad/preguntas, 1200×800.

## Cómo subirlas desde Android
1. Abre el repositorio GitHub `macabro10000/Manual---jugador`.
2. Cambia la rama a `lab/universo-frontend`.
3. Abre la carpeta `universo-lab/assets`.
4. Usa **Add file / Upload files** (Agregar archivo / Subir archivos).
5. Selecciona las imágenes del teléfono y confirma el commit en la rama `lab/universo-frontend`.

Si tu generador entrega JPG o PNG, puedes subirlos con esos formatos, pero habrá que actualizar la extensión correspondiente en `app.js` y en `index.html`. Lo más sencillo es exportar WebP o convertirlas a WebP antes de subirlas.

**Importante:** son imágenes de interfaz/miniaturas; no descargues ni subas videos de terceros. Para videos reales usa URLs y reproductores oficiales permitidos. No pongas claves privadas ni tokens en esta carpeta.
